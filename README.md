# Formúla 1 – Borðspil eftir Adam Szczubelek
# Inngangur
Höfundur: Adam Szczubelek

Hugmyndin að þessu borðspili er að búa til einfalt og skemmtilegt Formúlu 1 kappaksturs­spil þar sem leikmenn keppa á litlum kappakstursbílum um brautina. Spilið sameinar heppni og taktík: leikmenn kasta teningi með því að ýta á stóran hnapp, fá töluna upp á litlum skjá og færa bílinn sinn áfram eftir því. Markmiðið er að klára tvær hringferðir á brautinni og komast fyrstur í mark.
